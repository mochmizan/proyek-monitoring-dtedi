# AGENTS.md — dashboard

Parent: `AGENTS.md` (root) — DOX rail, stack, verification. This doc owns SPA-specific contracts.

## Purpose

React SPA for IoT smart-building monitoring. Live rooms/devices/alerts/map views polling HubGate V5 via same-origin `/api`.

## Ownership

- **dashboard/** owns SPA: routes, TanStack Query state, Zustand UI, build tooling.
- Root owns repo-wide rules, deployment, and cross-service contracts.

## Local Contracts

- **Stack**: React 19.2.7, TypeScript ~6.0.2, Vite 8.1.3, TanStack Router 1.170.17, TanStack Query 5.101.2, Zustand 5.0.14, Zod 4.4.3, Tailwind 4.3.2 (via `@tailwindcss/vite`), oxlint 1.71. Radix UI primitives (`radix-ui` for Dialog and Tooltip). `erasableSyntaxOnly:true` + `verbatimModuleSyntax:true` → `import type` only, no enums/namespaces. `@/*` → `./src/*`. Clean UTF-8 encoding maintained throughout (no mojibake).
- **Routes** (`src/routes/` → `routeTree.gen.ts` auto-generated, never edit): `/` (`index.tsx`), `/login`, `/alerts`, `/map`, `/hubs`, `/schedules`, `/users`, `/activity-logs`, `/settings`, `/room/$roomId`, `/device/$deviceId`.
- **Navigation & Preloading**: `App.tsx` configures `defaultPreload: 'intent'` with `defaultPreloadDelay: 50`, `defaultPendingMs: 100`, and `defaultPendingMinMs: 200`. Background idle route warmup runs in `__root.tsx` via `requestIdleCallback` (preloading `/hubs`, `/alerts`, `/map`, `/schedules`, `/settings` when authenticated). Top navigation progress bar displays on pending route transitions (`useRouterState({ select: (s) => s.status === 'pending' })`). Modal dialogs are split and lazy-loaded on demand (e.g. `ScheduleDialog` loaded via `React.lazy(() => import('@/components/schedules/ScheduleDialog'))` in `schedules.tsx`).
- **Layout Architecture & Canvas**: Flex-sibling layout in `RootLayout` (`__root.tsx`) wrapping the app in `TooltipProvider` with a flush edge-to-edge container (`p-0 gap-0`, no outer gutter padding). Features a desktop aside `AppSidebar` (`w-[260px]` expanded, `w-[68px]` collapsed, `duration-300`, `rounded-none`, `shadow-none`, backdrop-blur-xl, `border-r border-zinc-800/80`) and a mobile slide-over drawer powered by Radix UI `DialogPrimitive` (`w-[280px]`, `rounded-none`, `shadow-none`, `md:hidden`, smooth slide animations). Zero roundness (`rounded-none`) is maintained across internal sidebar components (`SidebarHeader` logo box and close button, `SidebarNav` nav links and alert badges, `SidebarFooter` avatar and sign-out button, and `SidebarTrigger` toggle button). Main viewport is a Canvas Area (`flex-1 flex flex-col min-w-0 h-full rounded-none border-0 shadow-none bg-zinc-900/40 backdrop-blur-xl overflow-hidden relative`) containing a Sticky Header (`SidebarTrigger`, route breadcrumb, live gateway status, alert bell link) and the scrollable main content area housing `<ErrorBoundary><Outlet /></ErrorBoundary>`. Sleek, modern custom scrollbars for dark theme are configured in `index.css` (`scrollbar-width: thin`, `scrollbar-color: #3f3f46 transparent`, 6px webkit scrollbars with `#27272a` thumb and `0px` radius). Keyboard shortcut `Cmd+B` / `Ctrl+B` (`useSidebarKeyboard` hook) toggles sidebar collapse, ignoring input/form elements.
- **Server state & Centralized Constants**: TanStack Query via `src/lib/api.ts` + `src/lib/queryKeys.ts` factory + `src/lib/queryClient.ts` + `src/lib/scheduleApi.ts`. All polling intervals, stale durations, and timeouts are centralized in `src/lib/constants.ts` implementing a Strict 4-Tier Polling Architecture with anti-stampede jitter (`src/lib/jitter.ts`, $\pm 15\%$) enforcing the Cache Harmony Invariant (`staleTime >= refetchInterval`): Tier 1 Ephemeral Commands (`POLL_TIER1_COMMAND_MS=1500`, `STALE_TIER1_COMMAND_MS=0`, fixed); Tier 2 Alerts & Critical Status (`POLL_TIER2_ALERTS_MS=6000`, `STALE_TIER2_ALERTS_MS=6000`, jittered); Tier 3 Operational Presence & Metadata (`POLL_TIER3_PRESENCE_MS=15000`, `STALE_TIER3_PRESENCE_MS=15000`, jittered); Tier 4 Analytical Trends & Sparklines (`POLL_TIER4_TRENDS_MS=60000`, `STALE_TIER4_TRENDS_MS=60000`, jittered); Static Entity Metadata (`STALE_METADATA_MS=300000`, `refetchInterval: false`). Backwards compatibility aliases (`POLL_MS`, `POLL_FAST_MS`, `STALE_MS`, `POLL_ALERTS_MS`, `POLL_SPARKLINES_MS`) map to tiered constants. Global query defaults in `queryClient.ts` enforce `refetchIntervalInBackground: false` across all queries, cleanly suspending polling in inactive background tabs. Root alert badge polling in `__root.tsx` uses Tier 2 jittered cadence gated with `enabled: !isLoginPage && !!currentUser`. Room lists in `/room/$roomId` and `/device/$deviceId` are static metadata (`staleTime: STALE_METADATA_MS`, `refetchInterval: false`). Settings Devices tab consolidates pending/active queries into a single `devices.list('all')` at Tier 3 cadence. Command dispatch uses `useCommandLifecycle` hook polling `GET /api/commands/{command_id}` every 1.5s with 12s timeout, immediate terminal failure abort (`failed`/`rejected`/`timeout`/`error`), case-insensitive `ACK`, and `visibilitychange` background pause with race-condition guard. ATS telemetry renders via `HistoryChart` 3-panel stacked layout (PLN Grid + Genset + Starter Battery DC with 11.8V warning / 11.2V critical threshold guides, independent Y-axes with chart panel header toggles controlling Auto Scale switching between dynamic 12% padded `computeYScale` and fixed preset ranges `PRESET_SCALES` rather than hiding series, synchronized X-axis across panels, and lifted crosshair/tooltip). `queryClient.ts` defaults: `placeholderData: keepPreviousData` (no blank refetch), `gcTime 5m`, `refetchOnWindowFocus: true`, retry predicate disables retries on HTTP 401 (`error instanceof ApiError && error.status === 401`). Mutations invalidate relevant keys. `FreshnessBadge` treats `dataUpdatedAt=0`/undefined as `Awaiting sync` (epoch-0 guard). `schedules` via `queryKeys.schedules` flexible cron `Asia/Jakarta`.
- **Pagination & Event Lists**: Standardized accessible `<Pagination>` component (`src/components/ui/pagination.tsx`) with First/Prev/Numbered/Next/Last navigation, dynamic ellipsis, items range summary (`Showing X–Y of Z`), and disabled loading states. Full-page `/alerts` stores `page` in URL search params validated via Zod (`page: z.number().int().positive().catch(1)`), fetches with `PAGE_SIZE=15` (`limit` and `offset`), uses `resetScroll: false` on `navigate` search updates to preserve scroll position, and uses `placeholderData: keepPreviousData` to prevent layout collapse during page turns. Device detail (`/device/$deviceId`) alert history paginates with `DEVICE_ALERT_PAGE_SIZE=10`, local `alertPage` state reset on device change, and `keepPreviousData`.
- **Room View & AC Telemetry**: `room.$roomId.tsx` provides full telemetry cards for TS, ATS, and AC nodes. AC cards render ambient room temp, humidity, plus AC1/AC2 power status (ON/OFF) and target setpoints. Floor plan marker tooltips render ambient temp/humidity and dual AC operational status on hover.
- **Dynamic Room Cards & Two-Pass Sparklines**: `RoomCard.tsx` is a pure presentation component (no internal `useQuery(fetchRoomMap)`). Supports 4 permutations: Section A (TS/AC Math.max instant readings + 6h room sparklines), Section B (ATS power state badge + <=11.8V warning / <=11.2V critical battery badges), Section A+B stacked, and Section C ("No sensors paired" placeholder). `index.tsx` fetches sparklines via single batch `queryKeys.rooms.sparklines('6h', 24)` (`refetchInterval: () => getJitteredInterval(POLL_TIER4_TRENDS_MS)`, `staleTime: STALE_TIER4_TRENDS_MS`), displays a responsive 4-per-row grid defaulting to 8 rooms with a centered glyph-only expand/collapse control when rooms > 8.
- **Client UI state**: React component state and URL search params via TanStack Router + Zod schemas for navigational state; persistent sidebar collapse preference in Zustand via `useSidebarStore` (`src/lib/sidebarStore.ts` with `persist` middleware storing `isCollapsed` under localStorage key `smsb-sidebar-pref`, plus ephemeral `isMobileOpen` drawer state).
- **Auth, CSRF & Error Containment**: `fetchCurrentUser` in `src/lib/api.ts` returns `null` on 401 without hard window redirects; `beforeLoad` in `__root.tsx` performs client-side router redirect to `/login?redirect=...` and globally redirects authenticated users with `must_change_password` to `/change-password`. Login bypasses the authenticated API wrapper, then the UI separately bootstraps a session-bound CSRF token. `ensureCsrfToken` stores tokens only in memory, coalesces concurrent loads and refreshes with one promise, adds `X-CSRF-Token` to unsafe methods, and retries at most once only for `CSRF_TOKEN_MISSING`/`CSRF_TOKEN_INVALID`; RBAC 403 responses are never retried. Logout clears the in-memory token on every attempt, but clears Query state and navigates to login only after server-side session revocation succeeds; failures leave the authenticated UI in place and surface an error. `<ErrorBoundary>` mounting hierarchy: mounted around `<Outlet />` in `src/routes/__root.tsx`, around the SVG chart canvas in `MultiPanelChartContainer.tsx`, and around the interactive canvas in `TopologyView.tsx`, isolating render exceptions from whole-page blanking; `QueryCache.onError` handles unhandled fetch failures.
- **Same-origin**: Vite proxy `/api`→`127.0.0.1:8000` (dev); Nginx `443`→`127.0.0.1:8000` (prod). No CORS.
- **Build**: `src/main.tsx` → `App.tsx` (Router + QueryClientProvider), `src/index.css` Tailwind 4 `@theme` (`--color-background:#09090b` `--color-primary:#6366f1`), `components.json` `new-york` shadcn, `src/types/api.ts` matches HubGate Pydantic models (including `CommandStatusResponse`), `src/lib/utils.ts` `cn()` = `clsx + tailwind-merge`, `src/components/ui/*` + `src/lib/cron.ts` cron helpers. Vite build leverages Rollup `manualChunks` code splitting: `vendor-react` (react, react-dom, scheduler), `vendor-tanstack` (Query & Router), `vendor-ui` (Radix UI, Lucide icons, Tailwind utilities), and `vendor-charts` (Recharts, XYFlow).
 
## Work Guidance
 
- Add route file in `src/routes/` — plugin regenerates `routeTree.gen.ts`.
- Sort/filter/range/page state for full views in URL search params with Zod `validateSearch` + `Route.useSearch()` (use `resetScroll: false` on `navigate` search updates to preserve scroll position on filter/page changes); not component state.
- Server state only via Query hooks + `queryKeys` factory; use `constants.ts` for `POLL_MS`/`STALE_MS`/`GAP_FLOOR_MIN`/`POLL_ALERTS_MS`.
- Command dispatch should use `useCommandLifecycle` to handle queuing, delivery status polling against `GET /api/commands/{command_id}`, timeout fallbacks, retry, and `CommandStatusBadge` feedback.
- Forms editing server-backed configuration (e.g. threshold config in `Controls.tsx`) must guard against background query refetch overwrites using `isDirty` state and focus tracking `isEditingRef`.
- Keep `src/components/` and `src/hooks/` splits (e.g., `device/HistoryChart`, `device/Controls`, `device/CommandStatusBadge`, `settings/RoomsTab`, `useDeviceHistory`, `useCommandLifecycle`).
- Wall-clock timestamps render `id-ID` + `timeZone: 'Asia/Jakarta'` + `' WIB'` everywhere (server stores UTC): `chartUtils.ts`, `dateUtils.ts`, `alerts.tsx`, `device.$deviceId.tsx`, `index.tsx`. Relative ages (`FreshnessBadge`, `hubs.tsx formatRelative`) use epoch diff - no TZ.
- Use `just` runner: `just dev` / `just lint` / `just build` / `just test`; do not add enums.
